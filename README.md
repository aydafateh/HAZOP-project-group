# 🏭 سامانه مدیریت ریسک پالایشگاه (HAZOP + هوش مصنوعی)

## 📌 معرفی پروژه

این پروژه یک **سامانه کامل مدیریت ریسک** برای پالایشگاه‌های نفت است که بر اساس استاندارد **HAZOP (Hazard and Operability Study)** طراحی و پیاده‌سازی شده است.  
سیستم با استفاده از **هوش مصنوعی (مدل XGBoost)** سطح ریسک عملیات‌های پالایشگاه را پیش‌بینی کرده و به صورت **بلادرنگ** وضعیت واحدهای مختلف را نمایش می‌دهد.

## 🎯 اهداف پروژه

- پیاده‌سازی استاندارد HAZOP در یک سامانه نرم‌افزاری

## ✅ قابلیت‌های پیاده‌سازی شده

### 🔐 احراز هویت و مدیریت کاربران
- ثبت‌نام کاربر جدید (نام کامل، کد ملی ۱۰ رقمی، تلفن، نام کاربری، رمز عبور)
- اعتبارسنجی کامل ورودی‌ها (کد ملی، تلفن، قدرت رمز عبور)
- دو نقش: ادمین (دسترسی کامل) و اپراتور (دسترسی محدود)
- افزودن و حذف اپراتور توسط ادمین

### 🧠 هوش مصنوعی و پیش‌بینی
- مدل XGBoost با دقت ~۸۵٪
- پیش‌بینی سه سطح ریسک: Low / Medium / High
- تحلیل ریشه علت (RCA) خودکار (تشخیص علت افزایش ریسک)

### ⚡ بلادرنگ و شبیه‌سازی
- شبیه‌ساز خودکار سنسورها (دما، فشار، جریان، سطح) هر ۵ ثانیه
- اتصال WebSocket برای به‌روزرسانی لحظه‌ای داشبورد

### 📊 ماتریس ریسک ۵×۵
- شدت پیامد (S1 تا S5) × احتمال وقوع (L1 تا L5)
- طبقه‌بندی: Acceptable / ALARP / Unacceptable
- نمایش گرافیکی ماتریس با رنگ‌بندی

### 🌳 درخت طبقه‌بندی خطر HAZOP
- ۶ دسته اصلی خطر (فرآیندی، آتش، سمی، مکانیکی، انسانی، کنترلی)
- زیرمجموعه‌ها با گایدوردهای اختصاصی

### 📋 سناریوهای HAZOP
- تعریف سناریوی جدید (نام، واحد، انحراف، علت، پیامد، اقدامات کنترلی)
- انتخاب احتمال و شدت → محاسبه خودکار امتیاز ریسک
- لیست تمام سناریوها با قابلیت حذف (فقط ادمین)

### ⚙️ تنظیمات پویا (Set Points)
- ویرایش آستانه مجاز دما و فشار توسط ادمین
- نمایش محدوده کم‌خطر، متوسط، پرخطر

### 📄 گزارش‌گیری
- خروجی PDF کامل از کل داشبورد (با قابلیت چاپ)
- خروجی Excel از تاریخچه پیش‌بینی‌ها
- پشتیبان دیتابیس* (فقط ادمین)

### 📈 نمودارها
- نمودار دایره‌ای آمار ریسک (Low/Medium/High)
- نمودار روند سنسورها (دما، فشار، جریان، سطح) با Canvas

### 📱 PWA (قابل نصب روی موبایل)
- قابلیت نصب روی گوشی و لپ‌تاپ (مثل اپلیکیشن)
- اجرا بدون نوار آدرس مرورگر
- آیکون اختصاصی روی صفحه اصلی دستگاه

### 🎨 رابط کاربری
- پالت رنگی آبی-سرمه‌ای (تم اختصاصی)
- هدر با پس‌زمینه عکس و افکت پارالاکس
- فوتر با مشخصات تیم، استاد، دانشگاه و تاریخ
- طراحی ریسپانسیو (سازگار با موبایل و دسکتاپ)

# نصب کتابخانه:
- در بخش cmd کتابخانه مورد نیاز را نصب کنید 

```bash
pip install fastapi uvicorn xgboost scikit-learn numpy pandas python-socketio openpyxl
```
- در صورتی که در نت ملی مشکلی ایجاد شد از آینه داخلی استفاده کنید :
